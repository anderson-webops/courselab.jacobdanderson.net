Score and model

Regional sampled FoM = W / [√(N + 100) × (100 × Georgia misses + outside reception)]. This teaching score assumes W = 1 for a valid nonempty model. Counts use this coarse regional grid; the assignment uses its original raster and separate whole-Earth sidelobe checks.

Absolute gain uses the full forward-hemisphere power integral, with normalization Q = —. Map threshold: −80 dBm. Receive gain: 10 dBi. The boundary is schematic.

1. Put the satellite, target and array in one geometry

The target ray starts at the satellite. A station’s look-angle ray starts at the ground and points the other way. In each calculation, express both positions in the same frame, subtract in the required direction, then project the ray onto that observer’s local axes. An array aimed at Georgia can be broadside to the target; a nadir-facing array usually needs an electronic scan.

2. Build the aperture from sites and feeds

The lattice sets allowed positions; it does not force every site to contain a feed. At frequency f, wavelength λ = c/f and a half-wave lattice has spacing λ/2. The feed phasor a exp(jψₙ) supplies the electrical excitation. The element’s own radiation pattern supplies another directional factor. Equal feed magnitudes allow phase and site selection while excluding arbitrary amplitude tapering for the assigned ideal model.

4. Steer in two coordinates and inspect the visible region

Fig. 4 shows a planar array in direction-cosine coordinates. Local u and v are the ray’s components along the two aperture axes. The visible forward hemisphere satisfies u² + v² ≤ 1. Phase gradients move the coherent peak; aperture dimensions control its angular widths. A point on this plot is a direction, rather than a latitude and longitude.

Inspect the full pattern, including sidelobes and possible grating lobes. A narrow main lobe alone does not establish either absolute gain or low out-of-state reception. The ideal model neglects mutual coupling; a physical implementation would need an embedded-element or full-wave model.

5. Normalize the whole pattern before assigning watts

Fig. 5 follows AF → |AF|²Gₑₗ → angular integration → directivity → gain. A peak-normalized image gives shape. The solid-angle integral gives the reference needed for D = 4πp/∫p dΩ. The integral includes every radiating direction; a zero backward hemisphere still belongs to the full-sphere average.

Radiation efficiency gives G = ηradD. Transmit power then sets the absolute intensity. Increasing all field amplitudes scales both the relative intensity and its integral, leaving directivity unchanged. This separation prevents counting the coherent array peak twice in a link budget.

Relative power p
|AF|²Gₑₗ before normalization to an absolute transmitted-power reference.
Directivity D
Directional intensity divided by its full-sphere average.
Gain G
Directivity multiplied by radiation efficiency for the stated power reference.

6. Carry the beam through the transmission path

Fig. 6 shows the power ledger from transmitter to receiver. Evaluate transmit gain in the actual satellite-to-pixel direction, and use that pixel’s slant range in free-space loss. Add receive gain and any specified losses using compatible power references. Angle-dependent gain and geometric spreading both affect the map.

For a far-field free-space link, Pr = PtGtGr(λ/4πR)². In logarithmic units, convert every gain and loss to dB and keep dBW versus dBm consistent. A receiver’s azimuth and elevation tell an antenna where to point; they are separate from the satellite aperture’s local steering coordinates.

7. Turn received power into a coverage decision

For the actual project, compute received power at every original map cell, apply the stated threshold, and compare that Boolean mask with the Georgia mask. Preserve the supplied raster resolution for the pixel-based score. Count installed elements using the assignment’s definition, and compare designs with the stated score after all eligibility and correctness conditions are applied.

Area is a separate geographic calculation. For longitude/latitude cell edges on a spherical Earth, A = R² Δλ [sin φnorth − sin φsouth], with angles in radians and R in kilometres for square kilometres. Latitude changes the area per angular cell, so a pixel count and a physical square-kilometre estimate should retain their own labels. Check sidelobes across the relevant visible Earth, not only the target bounding box.

Inside miss
A target cell whose received power falls below the threshold.
Outside reception
A non-target cell whose received power meets or exceeds the threshold.

8. Keep geometry, radiation and judging in one traceable chain

Test each stage with a simple case: a known frame rotation, an in-phase broadside sum, an isolated element with known directivity, a link whose range doubles, and a map mask with known counts. Then vary the allowed design parameters and compare complete evaluated designs. Numerical or optimizer convergence is separate from physical-model correctness.

Model check
A comparison with an independent physical result or limiting case.
Numerical convergence

Practice

1. Which parts of the calculation change when the physical aperture normal rotates while the satellite and target stay fixed?

Separate Earth-fixed line-of-sight geometry from the array’s local coordinate system.

The Earth-fixed ray, slant range and ground-station look angles stay the same. Its array-local direction cosines and scan angle change, so the element pattern, phase needed to steer toward the target and directional transmit gain can change.

2. If a pattern image is rescaled so its largest value is one, what further calculation is needed before using it in Friis transmission?

Follow Fig. 5: the power denominator is an angular integral, rather than the peak value.

Integrate the full relative element-times-array power pattern over solid angle to compute absolute directivity, then apply radiation efficiency and any required mismatch reference to obtain gain. Use directional gain and the correct transmit-power reference in Friis.
